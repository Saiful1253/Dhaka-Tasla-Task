# Dhaka Tesla Pool

This folder holds the working documents for the take-home challenge:

- `read.md` — deep analysis of the PRD (requirements, rubric, pitfalls, what NOT to do)
- `plan.md` — 2-day build plan with hour-by-hour tasks, diagrams (architecture/ERD/lifecycle/sequence), and checkboxes
- `README.md` — the project README (summary, architecture, ERD, setup, tests, AI usage, video)
- `backend/` — Express + TypeScript + Prisma API
- `frontend/` — Next.js app (Day 2)
- `docker-compose.yml` — `docker compose up` brings up DB + API with migrations, seed, healthchecks
